# 🛍️ Vitta Store

> Sistema de gestão comercial desenvolvido para simular a rotina de gerenciamento de um pequeno negócio.

O **Vitta Store** é uma aplicação web desenvolvida com **React e JavaScript**, criada para praticar e demonstrar conceitos de desenvolvimento front-end, gerenciamento de estado, componentes, persistência de dados e construção de interfaces administrativas.

O projeto possui uma interface de painel administrativo com módulos para gerenciamento de produtos, vendas, estoque, relatórios e configurações.

## 💾 Persistência de dados

Atualmente, o Vitta Store utiliza o **LocalStorage do navegador** para manter os dados mesmo após atualizar ou fechar a página.

Os dados persistidos incluem:

* Produtos
* Vendas
* Movimentações de estoque
* Configurações
* Página atual do sistema

> A utilização do LocalStorage faz parte da etapa inicial do projeto. A próxima evolução planejada é substituir essa estrutura por uma API e banco de dados.
